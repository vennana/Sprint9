# Sprint 9 — Foodgram

Учебный проект с автотестами Selenium на Python.

## Что проверяется

- регистрация пользователя;
- обязательность полей регистрации;
- переход между регистрацией и авторизацией;
- успешная авторизация;
- авторизация с неверным паролем;
- обязательность полей рецепта;
- добавление ингредиента;
- создание рецепта с изображением;
- переход к созданию рецепта через меню.

## Структура

- `pages/` — Page Object и отдельный файл локаторов;
- `tests/` — тесты и фикстуры;
- `data/` — тестовые данные;
- `assets/` — изображение для загрузки;
- `config/` — настройки браузера Selenoid;
- `.github/workflows/` — GitHub Actions.
